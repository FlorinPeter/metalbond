Key Principle: THE CREATOR OWNS THE LIFECYCLE
- handle() creates connection → handle() closes connection
- Workers use connection → Workers signal when done

2. GOROUTINE COORDINATION MECHANISM
═══════════════════════════════════════════════════════════════════════════════

The Coordination Strategy: stopRxLoop Flag + Sleep Pattern
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When Reset() or Close() is called, the system uses a TWO-STEP coordination:

Step 1: Signal Workers to Stop
Step 2: Wait for Clean Exit (1 second sleep)
Step 3: Close Connection (after workers exit)

┌─────────────────────────────────────────────────────────────────────────────┐
│                    Reset() Coordination Sequence                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Reset() called                                                             │
│      │                                                                       │
│      ├─→ Line 787: p.stopRxLoop = true    ┐                                │
│      │                                     │ Signal Phase                   │
│      ├─→ Line 771: p.txChanClose ← true   │                                │
│      │                                     │                                │
│      ├─→ Line 773: p.keepaliveStop ← true ┘                                │
│      │                                                                       │
│      v                                                                       │
│  Sleep 1 second (Line 788)  ← COORDINATION WAIT                            │
│      │                         (Allows workers to see signals and exit)     │
│      │                                                                       │
│      v                                                                       │
│  Close connection (Line 791)  ← SAFE (workers already exited)              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

Safety Guarantee
━━━━━━━━━━━━━━━━

┌──────────────────────────────────────────────────────────────────────────┐
│                                                                          │
│  Timeline Guarantee:                                                     │
│                                                                          │
│  T+0ms:  Signals sent (stopRxLoop, txChanClose, keepaliveStop)         │
│  T+0ms:  txLoop sees signal (if waiting on select)                     │
│  T+0ms:  keepaliveLoop sees signal (if waiting on select)              │
│  T+???:  rxLoop sees signal (at next loop iteration)                   │
│  T+1000ms: Sleep completes                                              │
│  T+1000ms: Connection closed                                            │
│                                                                          │
│  Guarantee: All workers exit within 1 second                            │
│             Connection closed AFTER all workers exit                    │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

3. OUTGOING CONNECTION FLOW (Client Mode)
═══════════════════════════════════════════════════════════════════════════════

Complete Lifecycle: Birth to Death
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 1: CREATION                                                          │
│  ═════════════════                                                          │
│                                                                             │
│  metalbond.AddPeer(addr) called                                            │
│         │                                                                   │
│         v                                                                   │
│  newMetalBondPeer(nil, addr, ..., OUTGOING, m)                             │
│         │                                                                   │
│         ├─→ peer.conn = nil  (no connection yet)                           │
│         ├─→ peer.direction = OUTGOING                                      │
│         │                                                                   │
│         v                                                                   │
│  go peer.handle()  ← START COORDINATOR                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 2: CONNECTION ESTABLISHMENT                                          │
│  ══════════════════════════════════                                         │
│                                                                             │
│  handle() starts (Line 314)                                                │
│         │                                                                   │
│         v                                                                   │
│  defer func() {                                                             │
│      // Will close connection when handle() exits                          │
│      if p.conn != nil {                                                     │
│          (*p.conn).Close()  ← OWNER CLEANUP                                │
│      }                                                                      │
│  }()                                                                        │
│         │                                                                   │
│         v                                                                   │
│  Create channels (shutdown, txChan, etc.)                                  │
│         │                                                                   │
│         v                                                                   │
│  for p.conn == nil {  ← ESTABLISH CONNECTION LOOP                          │
│      ┌────────────────────────────────────┐                               │
│      │ Try to connect:                    │                               │
│      │   tcpConn, err := net.DialTCP()    │                               │
│      │                                     │                               │
│      │ If success:                         │                               │
│      │   p.conn = &conn                    │                               │
│      │   break                             │                               │
│      │                                     │                               │
│      │ If failure:                         │                               │
│      │   Sleep random interval             │                               │
│      │   Retry                             │                               │
│      └────────────────────────────────────┘                               │
│         │                                                                   │
│         v                                                                   │
│  Connection established ✓                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 3: NORMAL OPERATION                                                  │
│  ══════════════════════                                                     │
│                                                                             │
│  Start worker goroutines:                                                  │
│         ├─→ go p.rxLoop()                                                  │
│         ├─→ go p.txLoop()                                                  │
│         └─→ (keepaliveLoop started after HELLO)                            │
│                                                                             │
│  Send HELLO message                                                         │
│         │                                                                   │
│         v                                                                   │
│  Main message processing loop:                                              │
│  ┌──────────────────────────────────────────────────────────────────────┐ │
│  │  for {                                                                │ │
│  │      select {                                                         │ │
│  │      case msg := <-p.rxHello:                                         │ │
│  │          p.processRxHello(msg)  → Start keepaliveLoop                │ │
│  │                                                                       │ │
│  │      case msg := <-p.rxKeepalive:                                     │ │
│  │          p.processRxKeepalive(msg)  → Connection ESTABLISHED         │ │
│  │                                                                       │ │
│  │      case msg := <-p.rxSubscribe:                                     │ │
│  │      case msg := <-p.rxUnsubscribe:                                   │ │
│  │      case msg := <-p.rxUpdate:                                        │ │
│  │          // Process messages                                          │ │
│  │                                                                       │ │
│  │      case <-done:  ← SHUTDOWN SIGNAL                                 │ │
│  │          p.cleanup()                                                  │ │
│  │          return  → defer closes connection                            │ │
│  │      }                                                                 │ │
│  │  }                                                                     │ │
│  └──────────────────────────────────────────────────────────────────────┘ │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 4: ERROR DETECTION                                                   │
│  ═══════════════════════                                                    │
│                                                                             │
│  Error occurs in rxLoop (read timeout, peer disconnect, etc.)              │
│         │                                                                   │
│         v                                                                   │
│  rxLoop: go p.Reset()  ← INITIATE RESET                                    │
│         │                                                                   │
│         v                                                                   │
│  rxLoop: return  (exits)                                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 5: COORDINATED SHUTDOWN (Reset for OUTGOING)                        │
│  ═════════════════════════════════════════════════                          │
│                                                                             │
│  Reset() executes:                                                          │
│         │                                                                   │
│         v                                                                   │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 1: SIGNAL WORKERS                      │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.stopRxLoop = true                         │                           │
│  │ time.Sleep(1 * time.Second)  ← WAIT         │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 2: CLOSE CONNECTION                    │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ if p.conn != nil {                          │                           │
│  │     (*p.conn).Close()  ← FALLBACK CLOSE     │                           │
│  │ }                                            │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 3: SHUTDOWN HANDLE                     │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.txChanClose ← true                        │                           │
│  │ p.shutdown ← true                           │                           │
│  │ p.keepaliveStop ← true                      │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 4: WAIT FOR WORKERS                    │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.wg.Wait()  ← WAIT FOR ALL GOROUTINES      │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 5: PREPARE RECONNECT                   │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.conn = nil                                 │                           │
│  │ p.wg = &sync.WaitGroup{}  (new instance)    │                           │
│  │ Sleep retry interval                         │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 6: RECONNECT                           │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.setState(CONNECTING)                       │                           │
│  │ go p.handle()  ← START NEW SESSION          │                           │
│  └─────────────────────────────────────────────┘                           │
│                                                                             │
│  New connection cycle begins...                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  handle() defer Execution (when handle() exits)                            │
│  ═════════════════════════════════════════════                             │
│                                                                             │
│  handle() receives shutdown signal                                         │
│         │                                                                   │
│         v                                                                   │
│  handle() cleanup()                                                        │
│         │                                                                   │
│         v                                                                   │
│  handle() return (exits main loop)                                        │
│         │                                                                   │
│         v                                                                   │
│  ┌────────────────────────────────────────────┐                            │
│  │ defer func() {                             │                            │
│  │   if p.conn != nil {                       │                            │
│  │     p.log().Debug("handle: closing TCP")   │                            │
│  │     err := (*p.conn).Close()               │  ← PRIMARY CLOSE           │
│  │     if err != nil {                        │    (or debug if already)   │
│  │       p.log().Debugf("already closed: %v") │                            │
│  │     }                                       │                            │
│  │   }                                         │                            │
│  │   p.log().Infof("handle done")             │                            │
│  │   p.wg.Done()                               │                            │
│  │ }()                                         │                            │
│  └────────────────────────────────────────────┘                            │
│                                                                             │
│  Connection cleanup complete ✓                                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  PHASE 6: COORDINATED SHUTDOWN (Reset for INCOMING)                        │
│  ════════════════════════════════════════════════════                       │
│                                                                             │
│  Reset() executes:                                                          │
│         │                                                                   │
│         v                                                                   │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 1: SIGNAL WORKERS                      │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.stopRxLoop = true                         │                           │
│  │ time.Sleep(1 * time.Second)  ← WAIT         │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 2: CLOSE CONNECTION                    │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ if p.conn != nil {                          │                           │
│  │     (*p.conn).Close()  ← FALLBACK CLOSE     │                           │
│  │ }                                            │                           │
│  └─────────────────┬───────────────────────────┘                           │
│                    │                                                        │
│                    v                                                        │
│  ┌─────────────────────────────────────────────┐                           │
│  │ STEP 3: CALL Close()                        │                           │
│  ├─────────────────────────────────────────────┤                           │
│  │ p.Close()  ← For INCOMING                   │                           │
│  │   ├→ setState(CLOSED)                       │                           │
│  │   ├→ stopRxLoop = true (again)              │                           │
